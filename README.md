## 🌟 Key Features

### 1. 🌌 3D Quantum Holo-Chamber (Three.js & WebGL)
- **7,000+ Quantum Particles**: Relativistic accretion disk swirl around a central black hole singularity with real-time physics.
- **Dynamic 3D Geometry Morphing**: Seamless transition between:
  - 🌀 **Accretion Vortex** (Relativistic gravitational disk)
  - 🪐 **Torus Knot** (Mathematical hyperdimensional surface)
  - 🧠 **Neural Realm** (3D spherical synaptic galaxy)
  - 🧬 **Cyber DNA** (Double-helix molecular matrix)
- **Floating 3D Node Crystals**: Pipeline nodes transformed into 3D faceted crystals connected by holographic 3D laser beams with raycast hover inspection and click selection.

### 2. ⚡ Infinite Spatial Canvas & Bezier Spline Physics
- **GPU-Accelerated Infinite Canvas**: Smooth pan (`Space + Drag`), zoom-to-fit (`F`), and cursor-centered zoom (`0.25x` to `2.5x`).
- **Interactive Bezier Spline Cables**: Cubic bezier curves with dynamic tension and magnetic port snap.
- **Signal Pulse Flow**: SVG particles traveling at 60 FPS along wires during pipeline execution.
- **Interactive Radar Minimap**: Live viewport radar in the corner with real-time node tracking and draggable lens.

### 3. 🎨 Micro-Canvases Inside Neural Blocks
Each neural block card features an interactive real-time micro-canvas:
- **Multimodal Sensor**: Live real-time visual/audio harmonic spectrum waveform.
- **Neural Agent Core**: Dynamic *Tree-of-Thoughts* decision tree with glowing junctions.
- **Episodic Vector Memory**: Live 2D cosine vector cluster scatter plot.
- **WASM Code Sandbox**: Live binary matrix and bytecode execution monitor.
- **Holographic Visualizer**: 3D rotating multi-axis geometric surface.

### 4. 🔊 Procedural Web Audio Engine (Sonic UI)
- 100% procedural sound synthesis using the native Web Audio API (zero audio files needed).
- Micro-clicks on hover/action, major harmonic chords on port connection, and pentatonic victory arpeggio on pipeline completion.

### 5. ⌨️ Raycast / Linear-Class Command Palette (`⌘K` / `Ctrl+K`)
- Instant fuzzy search overlay for keyboard-driven navigation (`↑`/`↓`/`Enter`/`Esc`).
- Auto-align nodes (`L`), zoom-to-fit (`F`), run mesh (`⌘↵`), and toggle 3D mode (`3` / `V`).

### 6. 📊 Real-Time Telemetry & Log Stream Studio
- High-frequency canvas sparkline charts: Token Velocity, Pipeline Latency, GPU Compute %, and Agent Confidence.
- Streaming log terminal with level filtering (`EXEC`, `INFO`, `WARN`, `SUCCESS`).

### 7. 🎭 Multi-Theme Design System
- **Obsidian Carbon** (Dark luxury with neon cyan & bio-emerald glow)
- **Cyber Titanium** (Deep laser slate with indigo accents)
- **Swiss Monochrome** (Minimalist Swiss typography)

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| <kbd>3</kbd> / <kbd>V</kbd> | Toggle 3D Quantum Holo-Chamber |
| <kbd>⌘</kbd> + <kbd>Enter</kbd> / <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Run Topological Pipeline Mesh |
| <kbd>⌘K</kbd> / <kbd>Ctrl+K</kbd> | Open Command Palette |
| <kbd>A</kbd> or <kbd>Tab</kbd> | Open Quick Node Picker (1-7) |
| <kbd>Space</kbd> + <kbd>Drag</kbd> | Pan Canvas Viewport |
| <kbd>Scroll</kbd> | Smooth Zoom (2D & 3D) |
| <kbd>F</kbd> | Zoom to Fit Viewport |
| <kbd>L</kbd> | Auto-Align Layout |
| <kbd>Esc</kbd> | Exit 3D Mode / Close Modals |

## 🛠️ Local Development

```bash
# Clone repository
git clone https://github.com/SebastianBasante20/aether-os.git
cd aether-os

# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build production bundle
npm run build
```
